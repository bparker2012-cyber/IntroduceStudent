# IntroduceStudent

## App Description

IntroduceStudent allows users to enter their name and school, select their academic year, choose the number of pets they own, indicate whether they want more pets, and generate a personalized introduction.

## Required Features

- [x] App displays an image of a school's logo
- [x] App has three text fields for first name, last name, and school name
- [x] App has a segmented control that changes the student's academic year
- [x] Number of pets label is increased or decreased using a Stepper
- [x] Switch makes a statement about whether the user wants more pets
- [x] Introduce Self button displays an alert containing the introduction and a dismissal button
